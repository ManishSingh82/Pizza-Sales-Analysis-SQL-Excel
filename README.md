# Pizza-Sales-Analysis-SQL-Excel
End-to-end pizza sales analysis using SQL and Excel with KPIs, trends, and an interactive dashboard for business insights.


## 📌 Project Overview
This project analyzes pizza sales data using **SQL** for data extraction and KPI calculation, and **Microsoft Excel** for building an interactive dashboard.  
The objective is to uncover **sales trends, peak hours, customer behavior, and product performance** to support data-driven business decisions.

---

## 🛠 Tools & Technologies
- **SQL** – Data querying, aggregations, KPI calculations  
- **Microsoft Excel** – Pivot Tables, Charts, Slicers, Dashboard design  
- **Data Analysis** – Business insights and trend analysis  

---

## 📊 Key Performance Indicators (KPIs)
Calculated using SQL:
- Total Revenue  
- Total Orders  
- Total Pizzas Sold  
- Average Order Value (AOV)  
- Average Pizzas per Order  

---

## 📈 Dashboard Analysis
The Excel dashboard highlights:
- 📅 **Daily Order Trend** – Orders peak on weekends and Fridays  
- ⏰ **Hourly Order Trend** – Highest orders between **12–2 PM** and **after 5 PM**  
- 🍕 **Sales by Pizza Category** – Classic category leads total sales  
- 📦 **Sales by Pizza Size** – Large size pizzas generate maximum revenue  
- ⭐ **Top 5 Best-Selling Pizzas**  
- ❌ **Bottom 5 Least-Selling Pizzas**  
- 📆 **Date Slicer** – Interactive time-based filtering

## 🧠 Key Business Insights
- Weekend evenings drive the highest order volume  
- Classic Deluxe Pizza is the top revenue and order contributor  
- Brie Carre Pizza is the lowest-performing product  
- Large-size pizzas dominate overall sales contribution
